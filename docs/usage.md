# ZestDrop 五类文件版

版本 1.0.0，日期：2026-10-08。Windows x64 本地文件工具，常驻托盘，没有主页面。

## 使用

1. 在桌面或资源管理器选中文件，按住鼠标左键开始拖动。
2. 拖动时按 Shift，光标旁显示可转换的格式；移到目标格式上松手。
3. 拖动时按 Ctrl+Shift 可选择对应的高级工具。需要参数的操作会打开一个小工具窗口，调整后点击“保存新文件”。窗口会显示处理结果，并可取消任务或打开输出位置。读取大文件、生成预览和保存时，预览区顶部会出现一条细进度线（很快完成的操作不会显示），不会遮挡画面。

菜单出现后可以松开键盘，只需保持鼠标左键按住。先按 Shift 再补按 Ctrl 也能切换到工具菜单。拖拽过程中按 F8/F9 也可打开同样的菜单（F8 格式、F9 工具），可用于从其他程序开始的文件拖拽；不拖拽时 F8/F9 照常交给当前程序（例如 Excel 重新计算）。Shift 快捷方式用于从桌面或资源管理器开始的文件拖拽，普通打字不会触发。

格式转换和不打开参数窗口的工具，在桌面右下角显示处理卡片；批量任务显示真实已处理数量，单个任务无法测量百分比时使用动画提示。完成后卡片自动收起，不弹出主页面。

每个任务有自己的卡片，按开始顺序从上到下排列。卡片上的按钮：

- **暂停 / 继续**：冻结整个任务（包括 FFmpeg 等外部程序）并停止计时，继续时从暂停处接着处理。
- **取消**：停止该任务并清理未完成的临时文件；已暂停的任务也可直接取消。
- **隐藏**：只隐藏卡片，任务继续在后台运行，完成时托盘会发出通知。

同时最多运行 2 个任务，其余显示“等待处理”；暂停的任务会让出位置，下一个任务随即开始。有两个及以上任务时，顶部会出现汇总栏，可“收起”成一摞（只显示正在运行的任务）、“展开”列出全部，或“全部隐藏”。托盘菜单可重新显示进度、暂停或继续全部任务、取消全部任务。

界面支持简体中文和英文。首次启动跟随 Windows 显示语言，之后可在托盘菜单“语言 / Language”中切换，选择会保存。

ZestDrop 没有主窗口。启动时（以及程序已在运行时再次启动）会打开“欢迎使用”窗口，说明用法和托盘图标的位置；窗口里可以切换语言，也可以勾选“启动时不再显示此窗口”。双击托盘图标或在托盘菜单选择“使用方式”可随时再次打开。

Esc 取消浮动菜单。在操作区域外松手不提交任务。托盘右键可显示处理进度、暂停或取消全部任务、打开最近输出的文件夹、切换语言或退出。

转换结果保存在原目录，名称添加操作后缀；同名自动编号，不覆盖原文件。多页导出和视频分段会创建新文件夹。批量最多 200 个输入，一个文件失败不会阻止其余文件处理。

## 更多功能

- **合并相关工具**：单张图片或单个视频的工具达到 10 个或更多时，相关工具合为轮盘上的一项，在同一个窗口里打开，例如图片的“裁剪与旋转”“尺寸与压缩”“背景与水印”，视频的“剪辑时段与分段”“声音与字幕”“水印与打码”等。窗口顶部的标签切换工具；做完一项调整点“应用这一步”，接着在结果上做下一项，“撤销上一步”可退回，全部完成后点“保存新文件”只写出一次。“剪辑时段与分段”和“保存帧与 GIF”的每个标签各自保存。元数据、制作图标和文字识别始终单独显示。不到 10 个工具的文件不受影响。
- **两层轮盘**（可选）：也可改用两层轮盘：第一层显示分类，把文件移到某个分类上，外圈展开第二层轮盘列出该分类的工具。在欢迎窗口或托盘菜单“工具较多时的轮盘”中选择“合并相关工具”或“两层轮盘”。
- **移除位置信息**：图片和视频的工具菜单里有“移除位置信息”，一步删除拍摄地点（EXIF/XMP 中的 GPS、视频的位置标签），相机、日期和方向等其他信息保留；JPG 不重新压缩画面，视频直接复制音视频流。没有位置信息的文件会提示无需处理。可一次处理多张图片和多个视频。
- **自定义轮盘**：托盘菜单“自定义轮盘…”可按文件类型和菜单（格式 / 工具）调整选项顺序，第一项位于轮盘顶部，其余按顺时针排列。默认把上次使用的选项放在最前并标记 ↻，也可在此关闭。
- **外观**：托盘菜单“外观”可选“跟随系统”“浅色”或“深色”。之后打开的窗口使用新外观，浮动轮盘和进度卡片立即切换。
- **记住设置与预设**：工具窗口会记住上次使用的设置；在“预设…”里可以把当前设置“保存为预设”，以后一键套用。区域、时间和密码不会被记住。
- **压缩的大小快捷键**：压缩工具里的 8 / 25 / 50 / 100 MB 按钮会填入目标大小，适合邮件和聊天软件的上传限制。
- **复制结果**：保存后点“复制结果”，图片会复制成图片，文字识别结果复制为文本，其他文件复制为文件。
- **输出文件名**：新文件按用途命名，例如 `photo-rotated.jpg`、`clip-compressed.mp4`；托盘菜单“保存位置”可改为统一的输出文件夹。
- **托盘菜单**：“最近输出”列出最近处理的文件；“处理剪贴板里的图片或文件…”可直接处理刚复制的截图或文件。
- **资源管理器右键菜单**（仅免安装版）：托盘菜单勾选“资源管理器右键菜单”后，右键文件或文件夹选“用 ZestDrop 处理…”即可。Microsoft Store 版不支持这一项。
- **监视文件夹**：托盘菜单“监视文件夹…”可指定文件夹和处理方式（转换格式或沿用上次设置压缩）；新放入的文件会自动处理，结果保存在其中的“ZestDrop 输出”文件夹。
- **流程**：托盘菜单“流程…”把几个工具连成一串（每步使用该工具保存过的预设），流程会出现在对应文件的工具菜单里，如“缩小 → 加水印 → 压缩”。
- **文字识别**使用 Windows 自带的识别引擎，不增加安装包大小；需要在系统里为对应语言安装“光学字符识别”。

## Office 文档

- PPT/PPTX/PPTM/PPS/PPSX/ODP：PDF、逐页 PNG/JPG、TXT，以及 PPT/PPTX/ODP 格式互转。
- DOC/DOCX/DOCM/RTF/ODT：PDF、逐页 PNG/JPG、TXT、HTML，以及 DOC/DOCX/RTF/ODT 格式互转。HTML 保存为包含资源的文件夹。
- XLS/XLSX/XLSM/XLSB/ODS/CSV/TSV：PDF、分页 PNG/JPG、CSV、TSV、JSON、TXT，以及 XLS/XLSX/ODS 格式互转。多个工作表分别导出文本文件，JSON 保留所有工作表。
- F9 可选择页码导出 PDF、把多个 Office 文件按顺序合并成 PDF，以及查看/清理/修改现代 Office 文件的元数据。

PDF、图片、旧版格式与 ODF 的原生排版导出需要桌面版 Microsoft PowerPoint、Word 或 Excel。本机三者均已安装；其他电脑缺少相应应用时，会隐藏依赖该应用的转换选项。现代 PPTX/DOCX 的文本提取可独立运行，XLSX 文本数据可在没有 Excel 时读取缓存结果。

Office 文件只读打开，转换时不运行 VBA 宏、不更新外部工作簿链接。转换结束只关闭本次打开的文件；已有 Office 文档和应用窗口保留。宏格式另存为不含宏的格式会移除宏。Office 格式之间的兼容性与分页遵循所用 Office 引擎。

其他尚未支持的文件会明确显示“仅支持打包”和“打包 ZIP”等标签，这些操作不会转换文件内容。

## 工具窗口

- 图片/视频裁剪：预览上有一个裁剪框，初始为整张画面。拖动框内可移动位置，拖动四角或四边调整大小，框外的部分会变暗，所见即所保留的部分；拖动时框内会显示当前尺寸。也可以直接填写左侧 x、顶部 y、宽度和高度，框会同步变化。选择比例后裁剪框会锁定该比例，保存的尺寸与框显示的尺寸完全一致。“查看效果”可预览裁剪后的结果，“重置裁剪”恢复整张画面；视频可在播放器中选择“处理效果”。
- PDF 遮盖：在页面上拖动框选要遮盖的内容（可用“上一页/下一页”或页码切换页面，可添加多个区域），也可填写一段文字，文档中所有出现的位置都会被遮盖。框内的文字、图片和图形会从文件中真正删除，而不只是盖上黑块；旋转过的页面同样适用。单个 PDF 的“水印与遮盖”在同一个窗口里完成。
- 图片/视频打码：在预览上拖动选区，也可填写像素尺寸，可添加多个区域。图片修改参数后自动更新效果；视频可在播放器中选择“处理效果”。打码默认使用马赛克，可调整颗粒大小，也可选择模糊或纯色遮盖。多个区域可分别修改或移除。
- 图片/视频“旋转 / 翻转”：可输入或用滑块选择 0–360° 的任意角度（顺时针），也可左右或上下翻转；“向左转/向右转 90°”按钮在当前角度上每次加减一个直角。直角旋转无损；其他角度可选择放大画布以保留整张画面，或保持原尺寸并裁掉四角，空白处可填颜色（图片留空为透明，JPG 会变为白色）。预览会随角度、翻转和颜色的改动即时更新（视频直接在播放画面上预览）。可一次处理多张图片或多个视频；视频会重新编码，保留完整时长和音轨。
- 图片和视频裁剪都支持自定义宽高比例，包括 3:2、21:9、2.35:1 等。选择“自定义”后填写宽、高比例值。
- 视频“裁剪画面”只改变画面区域，保留完整时长和音轨；时间轴用于定位预览画面，不裁剪时段。
- 所有音视频工具窗口都有播放器，提供播放/暂停、进度拖动、当前时间、音量和静音。原文件可以完整播放；不兼容的格式会准备本地兼容播放文件。多文件操作可切换要播放的输入。
- 支持效果播放的工具提供“原文件 / 处理效果”切换；效果播放为当前位置最多 30 秒的片段，进度条移到片段外会重新准备播放。保存处理完整文件或选择，不受预览片段长度限制。
- 视频和音频的时段工具提供开始/结束设置；设定时段或拖选打码区域前切换到“原文件”。保存视频帧提供逐帧定位。
- 播放器使用黑色控制栏和细进度条。裁剪时段可拖动时间线上的橙色开始/结束节点，选中区间会高亮；节点与右侧时间参数双向同步。处理效果模式下不编辑裁剪节点，先切换回原文件。
- 音频蜂鸣：在波形上选择多个时段。
- 元数据：按文件、轨道、章节查看和搜索；关闭“移除全部”后编辑表格中的字段和值。
- 合并、拼图和拼接：通过列表调整文件顺序。
- PDF 页管理：调整页列表，复制或移出页面；也可直接输入页码顺序和旋转角度。

## 范围和限制

所有处理在本机完成。多图像 HEIC、MPO/JPEG、多页 TIFF 及其他多帧图片在 F9 中可切换图像帧，默认读取主图（或第一帧），导出当前选中的单帧，原文件全部帧保留。GIF 动画使用视频转换入口。图片处理上限为 8000 万像素。

PDF 转 Word 的版式可能变化；扫描页可作为图片写入 Word。PDF 提取 TXT 需要原文件有可选文字；扫描件可先用“文字识别”。PDF 页图导出为 300 DPI。PNG/WebP/HEIC/AVIF/TIFF 保留支持的透明度，JPG/BMP 使用白底。

目标大小受格式、内容和编码器限制；无法达到时报告失败，不把超出目标的输出当作成功。常规有损压缩不保证每个输入都会变小。加密、损坏或不支持的输入会报告错误。

可在托盘菜单或欢迎窗口开启“开机自启”。当前没有自动更新或安装器。Windows 多屏、所有缩放比例和每个工具窗口的人工交互尚未逐项验证。

## 运行与源码

完整解压后运行 ZestDrop.exe，保留同目录的 backend、runtime 和所有 DLL。已随包提供 .NET 8 桌面运行时、Python、FFmpeg、7-Zip 和所需 Python 库，无须另装这些依赖。

source/ 为当前 C# 源码和 Python 处理代码；validation/ 保存测试报告。运行日志和临时预览文件保存在 %LOCALAPPDATA%\ZestDrop\logs，日志超过 4 MB 自动轮换，不记录处理文件的完整路径，也不包含在发布压缩包中。

第三方许可保留在 .NET/Python/FFmpeg/7-Zip 的运行目录和 Python 各个 dist-info 目录中，具体版本和来源见依赖清单.json。
