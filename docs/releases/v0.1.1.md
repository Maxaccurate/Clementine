## ZestDrop v0.1.1

This update adds the ZestDrop icon and easier shortcuts for desktop file drags.

### What's new

- **Shift** opens the conversion menu while dragging a file from the desktop or File Explorer.
- **Ctrl+Shift** opens the tools menu. Pressing Ctrl after Shift switches to tools immediately.
- Once the menu appears, you can release the keyboard keys and keep holding the mouse button until dropping onto an operation.
- **F8/F9 remain available** as alternative shortcuts.
- Modifier shortcuts require mouse movement from a shell file window; ordinary Shift typing does not open the menu. Non-file drags are dismissed, and Escape cancels the menu for the current drag.
- Switching menus preserves the dragged files and keeps operations in copy mode so originals are preserved.
- New application, tray, and window icons, with nine sizes from 16px to 256px.
- Updated README and tray instructions.

### Download and upgrade

Download `ZestDrop-v0.1.1-windows-x64.zip`, extract the entire archive, and run `ZestDrop.exe` from the `ZestDrop` folder. Keep its `backend`, `runtime`, and DLLs together. The bundle includes .NET, Python, FFmpeg, 7-Zip, and the required Python libraries.

Before upgrading, finish or cancel current jobs and quit the old application from its tray menu. Extract this version into a fresh directory and launch it. A SHA-256 checksum is attached.

### Requirements and validation

- Windows x64; the interface is currently in Chinese.
- Office layout exports require the corresponding desktop Microsoft PowerPoint, Word, or Excel application.
- The executable is unsigned. There is no installer, auto-update, or startup registration.
- Shortcut state checks cover modifier ordering, held keys, Escape, and unrelated mouse/keyboard interactions. Actual file-drag events have also been observed with the new shortcuts; broader testing across Explorer configurations and display scaling is still needed.
- Existing PDF/OCR and multi-frame image limitations continue to apply; see the [usage guide](https://github.com/Maxaccurate/ZestDrop/blob/main/docs/usage.md).

Report reproducible bugs in [Issues](https://github.com/Maxaccurate/ZestDrop/issues). Please avoid uploading private input files.
