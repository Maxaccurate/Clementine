## ZestDrop v0.1.1

A small update that prepares ZestDrop for packaged installs and adds license notices. Conversions, tools and the interface work exactly as in v0.1.0.

### What's new

- **Third-party notices.** A new **Third-party notices** item in the tray menu opens `THIRD-PARTY-NOTICES.txt`, which lists every bundled component (FFmpeg, 7-Zip, Python, .NET and the Python packages) with its license and where to get its source code.
- **Runs from a read-only folder.** ZestDrop no longer writes anything next to its own files: Python no longer creates bytecode caches there, and command-line results fall back to `%LOCALAPPDATA%\ZestDrop\logs`. This is required for packaged installs.
- **Microsoft Store package.** The repository now includes the Store package manifest, logo assets and `package-msix.ps1`, which builds the `.msix`. See the README.
- Small wording fix: the menu and tool window say "1 file" instead of "1 file(s)".

### FFmpeg source code

The bundled FFmpeg 9.0.2 is a GPLv3 build. Its exact source code is attached to the [v0.1.0 release](https://github.com/Maxaccurate/ZestDrop/releases/tag/v0.1.0) as `ffmpeg-9.0.2.tar.xz` (also available from https://ffmpeg.org/releases/ffmpeg-9.0.2.tar.xz).

### Download and upgrade

Download `ZestDrop-v0.1.1-windows-x64.zip`, extract the entire archive, and run `ZestDrop.exe` from the `ZestDrop` folder. Keep its `backend`, `runtime`, and DLLs together. The bundle includes .NET, Python, FFmpeg, 7-Zip, and the required Python libraries. No separate installation is needed.

Before upgrading, finish or cancel current jobs and quit the old application from its tray menu. Extract this version into a fresh directory and launch it. Your language choice and logs are kept in `%LOCALAPPDATA%\ZestDrop`. A SHA-256 checksum is attached.

### Requirements and notes

- Windows x64. The interface is available in English and Simplified Chinese; switch it from the tray menu (Language / 语言).
- Office layout exports need the corresponding desktop Microsoft PowerPoint, Word, or Excel application.
- The executable is unsigned, so Windows SmartScreen may warn on first run. Compare the download with the attached SHA-256 checksum.
- There is no installer, auto-update, or startup registration.

Report reproducible bugs in [Issues](https://github.com/Maxaccurate/ZestDrop/issues). Please avoid uploading private input files.
