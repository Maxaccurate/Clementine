## ZestDrop v0.0.1

**Drag. Drop. Convert.** The first public release of ZestDrop, an open-source desktop file utility for Windows.

### Download and run

- Download `ZestDrop-v0.0.1-windows-x64.zip` below.
- Extract the entire archive and run `ZestDrop.exe` inside the `ZestDrop` folder.
- Keep the `backend` and `runtime` folders and all DLLs beside the executable.
- This portable bundle includes .NET, Python, FFmpeg, 7-Zip, and the required Python libraries. No separate installation of these runtimes is needed.
- A SHA-256 checksum file is provided alongside the ZIP.

### Features

- Drag files on the desktop or in File Explorer and press **F8** to choose a conversion format, or **F9** to choose a tool.
- Tools for images, video, audio, documents, and archives.
- Image adjustments, backgrounds, custom-ratio cropping, and pixelation with adjustable block size.
- Video trimming, cropping, speed changes, joining, frame capture, splitting, and redaction.
- Audio loudness normalization, channel controls, trimming, and beep redaction.
- PDF export and page management, plus Office document conversion through installed desktop Office applications.
- ZIP, TAR, GZIP, and RAR packing and extraction. RAR output uses store mode.
- Progress indicators for loading, previews, saving, and background jobs, with elapsed time and actual processed counts for batches.
- Outputs are saved alongside the inputs with collision-safe names; original files are preserved.

### Requirements and limitations

- Windows x64. The interface is currently in Chinese.
- Native Office layout exports require the corresponding desktop Microsoft PowerPoint, Word, or Excel application.
- The executable is currently unsigned.
- PDF-to-Word layout may differ from the original; scanned PDFs do not have OCR text extraction.
- Multi-frame image editing exports the selected frame while preserving the original input file.
- No installer, automatic updates, or startup registration are included.
- Some manual interactions, display scaling configurations, and multi-monitor arrangements still need broader testing.

The bundle includes project source, validation records, and third-party license files. Project source uses MIT; third-party components retain their own licenses. Please report reproducible bugs in [Issues](https://github.com/Maxaccurate/ZestDrop/issues), including the tool, input format, Windows version, and expected behavior. Avoid uploading private files.
