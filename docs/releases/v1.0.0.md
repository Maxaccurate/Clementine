## ZestDrop v1.0.0

The first full release. ZestDrop grows from a converter into a small toolbox: about twenty new tools, related tools combined into one window, presets and flows, watched folders, and a cleaner wheel.

### Combined tool windows

When a single picture or video has ten or more tools, related tools now share one wheel entry and one window, so the wheel stays at eight entries:

- **Pictures:** Crop & rotate · Size & compress · Edit image · Background & watermark · Redact · Metadata · Make icons · Text recognition (OCR)
- **Videos:** Trim & split · Speed & effects · Crop & rotate · Resolution & compress · Sound & subtitles · Watermark & redact · Frames & GIF · Metadata

Each tool in a combined window is a tab. Make one change, click **Apply this step**, and the next change works on the result; **Undo last step** takes the newest change back, and **Save new file** writes the result once. (Trim & split and Frames & GIF save from each tab, as before.) Files with fewer than ten tools are unchanged.

Prefer categories? The two-wheel layout (pick a category, then the tool on a second wheel) can be chosen on the welcome screen or in the tray menu under **Wheel with many tools**.

### New tools

- **Pictures:** rotate by any angle and flip (with a dial, and a live preview), resize, watermark (text and/or logo, single or tiled), make icons (ICO or a website favicon set), text recognition, and animation / slideshow from several pictures (GIF or MP4).
- **Videos:** rotate and flip, resolution / frame rate, make a GIF, fade / reverse / loop, burn in subtitles or replace / mix the soundtrack, watermark, and a contact sheet of thumbnails.
- **Audio:** volume / fades / noise reduction, join audio, and phone ringtone (.m4r).
- **PDF:** add or remove a password, page numbers / header & footer, extract images, watermark, and text recognition for scanned PDFs (text, or a searchable PDF).
- **Archives:** ZIP or 7z with an AES-256 password and split volumes.

Text recognition uses the recogniser built into Windows, so it adds nothing to the download; Windows needs the "Optical character recognition" feature for the language you read.

### Easier to work with

- **Cropping** shows a frame on the picture: drag it to move, drag a corner or edge to resize, and the size shown is exactly the size saved, also with a fixed ratio.
- **Remembered settings and presets:** tool windows reopen with the settings you used last, and **Presets…** saves named settings for later. Regions, times and passwords are never stored.
- **Flows** (tray menu) chain several tools with their presets, such as "resize → watermark → compress", and appear in the tool menu for that kind of file.
- **Watched folders** (tray menu) process new files automatically and put the results in a "ZestDrop output" folder inside.
- **Save location:** save next to the original (default) or in one folder of your choice. **Recent results** lists the latest outputs.
- **Clipboard:** process a copied screenshot or copied files from the tray menu.
- **Explorer right-click menu** (portable version): "Process with ZestDrop…" on files and folders, switched on from the tray menu.
- **Start with Windows** can be switched on from the tray menu or the welcome window.
- **Copy result** after saving, size buttons (8 / 25 / 50 / 100 MB) for compression targets, and clearer output names such as `photo-rotated.jpg`.
- A new look for the floating wheel, a thin progress line instead of a busy card in tool windows, and the bundled Source Han Sans font for Chinese text.

### Fixes

- Photos with a colour profile (most phone photos) now keep their EXIF: the Metadata tool shows it, and editing one field no longer drops the others.
- **Remove metadata** on HEIC photos now really removes EXIF and XMP.
- When a job fails, the notification shows the engine's actual reason instead of a general message, and the completion note names the folder you chose to save in.

### FFmpeg source code

The bundled FFmpeg 9.0.2 is a GPLv3 build. Its exact source code is attached to the [v0.1.0 release](https://github.com/Maxaccurate/ZestDrop/releases/tag/v0.1.0) as `ffmpeg-9.0.2.tar.xz` (also available from https://ffmpeg.org/releases/ffmpeg-9.0.2.tar.xz).

### Download and upgrade

Download `ZestDrop-v1.0.0-windows-x64.zip`, extract the entire archive, and run `ZestDrop.exe` from the `ZestDrop` folder. Keep its `backend`, `runtime`, and DLLs together. The bundle includes .NET, Python, FFmpeg, 7-Zip, and the required Python libraries. No separate installation is needed.

Before upgrading, finish or cancel current jobs and quit the old application from its tray menu. Extract this version into a fresh directory and launch it. Your settings and logs are kept in `%LOCALAPPDATA%\ZestDrop`. If you later move the ZestDrop folder, **Start with Windows** follows it the next time you launch it; the Explorer right-click menu does not, so switch it off and on again from the tray menu. A SHA-256 checksum is attached.

### Requirements and notes

- Windows 10 version 1809 or later, x64. The interface is available in English and Simplified Chinese.
- Office layout exports need the corresponding desktop Microsoft PowerPoint, Word, or Excel application. Office conversions were not re-tested for this release.
- The executable is unsigned, so Windows SmartScreen may warn on first run. Compare the download with the attached SHA-256 checksum.
- There is no installer or auto-update.
- PDF compression re-encodes embedded images as JPEG, so transparency in those images is not kept.
- Automated checks pass for all backend conversions and tools (238 checks), advanced tool branches, tool parameters, progress and pausing, the welcome window and controls, and translations. Multi-monitor and display-scaling setups still need broader testing.

Report reproducible bugs in [Issues](https://github.com/Maxaccurate/ZestDrop/issues). Please avoid uploading private input files.
