## ZestDrop v0.1.2

A small update: ZestDrop now opens a welcome window instead of starting silently, and repeated conversions are faster.

### What's new

- **Welcome window.** ZestDrop has no main window, so launching it used to look like nothing happened. Now a short "Welcome to ZestDrop" window explains how to use it and where its tray icon is. It opens when ZestDrop starts, and again whenever you launch ZestDrop while it is already running, for example from the Start menu. It has English / 简体中文 buttons, and a **Don't show this window when ZestDrop starts** option. You can reopen it any time by double-clicking the tray icon or choosing **How to use** in the tray menu.
- **Faster conversions after the first few.** v0.1.1 stopped Python from keeping its precompiled-library cache, which a read-only install needs, but did not replace it, so every conversion recompiled the libraries. In our test an image conversion took about 1.75 s that way and now takes about 1.0 s. The cache now lives in `%LOCALAPPDATA%\ZestDrop\pycache` (about 4 MB; it is rebuilt automatically if you delete it). The first conversions after installing or upgrading are slower while it fills, and nothing is written into ZestDrop's own folder.
- The settings file also remembers your choice about the welcome window.

### FFmpeg source code

The bundled FFmpeg 9.0.2 is a GPLv3 build. Its exact source code is attached to the [v0.1.0 release](https://github.com/Maxaccurate/ZestDrop/releases/tag/v0.1.0) as `ffmpeg-9.0.2.tar.xz` (also available from https://ffmpeg.org/releases/ffmpeg-9.0.2.tar.xz).

### Download and upgrade

Download `ZestDrop-v0.1.2-windows-x64.zip`, extract the entire archive, and run `ZestDrop.exe` from the `ZestDrop` folder. Keep its `backend`, `runtime`, and DLLs together. The bundle includes .NET, Python, FFmpeg, 7-Zip, and the required Python libraries. No separate installation is needed.

Before upgrading, finish or cancel current jobs and quit the old application from its tray menu. Extract this version into a fresh directory and launch it. Your language choice and logs are kept in `%LOCALAPPDATA%\ZestDrop`. A SHA-256 checksum is attached.

### Requirements and notes

- Windows x64. The interface is available in English and Simplified Chinese; switch it from the tray menu (Language / 语言) or the welcome window.
- Office layout exports need the corresponding desktop Microsoft PowerPoint, Word, or Excel application. Office conversions were not re-tested for this release.
- The executable is unsigned, so Windows SmartScreen may warn on first run. Compare the download with the attached SHA-256 checksum.
- There is no installer, auto-update, or startup registration.
- Automated checks pass for the backend conversions, tool parameters, the progress stack, pausing and resuming a real FFmpeg encode, the welcome window, and translations. Multi-monitor and display-scaling setups still need broader testing.

Report reproducible bugs in [Issues](https://github.com/Maxaccurate/ZestDrop/issues). Please avoid uploading private input files.
